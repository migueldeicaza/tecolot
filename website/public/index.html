GETTING STARTED · {{ versionLabel }}

Make Tecolot yours

Install the signed macOS application, choose a profile, and start a local shell. The standard terminal behavior works without extra setup.

1 · Install

Download the latest DMG, open it, and drag Tecolot to Applications. Releases are signed and notarized for macOS.

Open the latest release ↗

2 · Choose a profile

Open Settings to create or duplicate a profile. A profile controls the shell, startup directory, environment, font, theme, cursor, background opacity, and terminal behavior. You can also import iTerm2 color schemes.
