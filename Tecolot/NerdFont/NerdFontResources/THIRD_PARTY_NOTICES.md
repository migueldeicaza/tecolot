# Third-party notices — Nerd Font symbols

Tecolot bundles the Symbols Nerd Font so that Nerd Font icons render when the
selected terminal font does not contain them.

- Asset: `SymbolsNerdFont-Regular.ttf` (PostScript name `SymbolsNF`)
- Project: Nerd Fonts — https://github.com/ryanoasis/nerd-fonts
- Release: v3.4.0 (tag `v3.4.0`, 2025-04-24)
- Source archive:
  https://github.com/ryanoasis/nerd-fonts/releases/download/v3.4.0/NerdFontsSymbolsOnly.zip
- License: MIT with component font licenses; see `LICENSE` in this directory.

The generated codepoint metadata in `Tecolot/NerdFont/` derives from the same
release's `glyphnames.json` (pinned in `tools/NerdFontMetadataGen/inputs/`).
The committed font and the generated metadata must always come from the same
Nerd Fonts release; `tools/NerdFontMetadataGen` validates this.
